Транспортный справочник

По заданному набору информации во входном JSON об остановках и автобусных маршрутах позволяет: 
* Построить карту автобусных маршрутов в формате svg
* Получить информацию об остановке или автобусе
* Построить наикратчайший маршрут между любыми остановками с учетом времени пересадки 
и расстоянием между остановками
